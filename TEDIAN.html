FILE NO. ACX-01 // ADVANCE SUPPORT FIGHTER

ASF-X Shinden II

震电 II —— 传承「震电」之名的超机动支援战机

由机械设计师河森正治操刀、致敬二战 J7W1「震电」的架空战机。上下纵列双发布局——上引擎机背进气、下引擎翼根进气，搭配可变前掠主翼、前置鸭翼与可变 V 型全动尾翼，可依速度切换气动布局，兼顾高速冲刺、低速缠斗与垂直起降。从《突击地平线》的试验机到《无限》背脊犬中队主力，再登陆《皇牌空战7》，跨越多个世界观续写空战传奇。

FILE NO. ACX-02 // STEALTH CARRIER-BORNE FIGHTER

XFA-27

「六翼天使」—— 系列首架可操纵的架空舰载机

系列中第一架可操纵的架空机，初登场于《皇牌空战2》。全可动前翼搭配可变后掠主翼，上下各两片共四片水平尾翼——起降时下方两片自动收折避免触地；二维矢量喷嘴赋予出色的机动与稳定性，机首下方感应器让飞行员直视前下方环境，内置弹舱则带来部分雷达隐身能力。1998 年尤吉亚政变中，Scarface 1 驾驶它立下决定性战功。

可变后掠翼 四片平尾 内置弹舱
FILE NO. ACX-03 // STEALTH MULTIROLE FIGHTER

CFA-44 Nosferatu

「财政吸血鬼」—— 为空中航母而生的重型杀手

命名源自传说中的吸血鬼（Nosferatu）。三角翼搭配后掠鸭翼的半隐身设计，搭载两门电磁轨道炮（EML）、全向多目标导弹（ADMM）与电子对抗系统（IEWS）。为搭配 P-1112 空中航母而生，高昂造价耗尽艾托伐克的灾后重建资金，被媒体讥讽为「国家财政的吸血鬼」。其 12 连发微型导弹可瞬间清空战场，无人改型 QFA-44 更是「蝶使」的座机。

FILE NO. EXP-01 // S/MTD TECHNOLOGY DEMONSTRATOR

F-15 S/MTD

验证矢量与反推的技术先行者

美国空军短距起降与机动技术验证计划（S/MTD）的核心载体。装备的二维矩形喷管可实现俯仰 ±20° 矢量偏转并集成反推功能，矢量响应速度较传统圆形喷管提升 40%。试飞数据促使美国空军放弃反推要求、坚定了推力矢量路线；随后 NASA 在此基础上实施 ACTIVE 计划，升级轴对称三维矢量喷管——这些成果直接反哺了 F-22 战斗机的飞控系统研发。

二元矢量喷管 ±20° 偏转
FILE NO. EXP-02 // CRANKED-ARROW DELTA WING

F-16XL

竞标惜败的双三角翼多面手

通用动力自费 4900 万美元改装的 F-16 衍生验证机，共两架——单座 XL-1 与双座 XL-2。机身前后加长，61 平方米石墨-聚酰胺复合材料箭形机翼取代常规机翼，起落架承载从 16 吨强化到 22 吨。149 种布局、3600 小时风洞试验锤炼出的箭形翼，兼具持续机动、大速度升阻比与更多外挂点；然而在双重任务战斗机竞标中不敌 F-15E，1985 年试飞结束后双双封存。

双三角翼 复合材料蒙皮
FILE NO. EXP-03 // STRIKE RAPTOR CONCEPT

FB-22 Strike Raptor

停留在图纸上的「打击猛禽」

洛克希德·马丁独立开发的中型战斗轰炸机概念方案。以现役 F-22 为基础共享零部件以压低成本，65° 后掠角三角机翼一直延伸到尾部，无尾设计省却垂直与水平尾翼，大幅压缩雷达侧影；燃料携带量比 F-22 多 80%，航程翻倍超过 3200 公里——多版概念图公布至今，始终停留在纸面。

FILE NO. TG-01 // SWING-WING FLEET DEFENDER

F-14A Tomcat

「雄猫」—— 舰队上空的不死鸟猎手

格鲁门为美国海军打造的变后掠翼、双座双发、双垂尾舰载战斗机。F-111B 项目夭折后，303 方案脱颖而出：可变后掠翼、休斯 AWG-9 雷达火控与 AIM-54「不死鸟」远程导弹构成舰队防空铁幕。1970 年 12 月原型机首飞，1972 年 5 月交付；1987 年换装改进发动机的 F-14B 投产，后续升级为 F-14D「超级雄猫」。

可变后掠翼 AIM-54 不死鸟
FILE NO. TG-02 // CARRIER MULTIROLE STRIKE FIGHTER

F/A-18E Super Hornet

「超级大黄蜂」—— 甲板上的多面手

1991 年 A-12 隐身攻击机计划取消后，波音在 F/A-18C/D 基础上改进的过渡机种。机身延长、翼展与机翼面积增大，换装两台 F414-GE-400 涡扇发动机（单台加力推力 97.9 千牛），航程与载弹量显著提升；AN/APG-73 多功能雷达与升级座舱显示，电子设备 90% 与 C/D 型兼容。1995 年 11 月首飞，2001 年投入使用，至今仍是美国海军甲板主力。

F414 涡扇 APG-73 雷达
FILE NO. TG-03 // FIFTH GENERATION FIGHTER

SU-57

俄罗斯首型隐身重型战斗机

由「PAK FA」计划发展而来的俄罗斯第五代单座双发隐身重型战斗机，原型机 T-50 于 2010 年 1 月首飞，2017 年正式定名，2020 年列装首架量产机。最大起飞重量 35000 千克，超音速巡航 1450 km/h，作战半径 1200 公里，内置 4 个武器舱——超机动、超巡与隐身的结合，是俄式航空美学的当代答卷。

第五代战机 超音速巡航
FILE NO. TG-04 // HYPERSONIC TEST AIRCRAFT

DarkStar

「暗星」—— 银幕上飞出 10 马赫的幽灵

《壮志凌云2》中的虚构高超音速飞机，道具由洛马臭鼬工厂设计、ADM Works 精密建造——70 英尺全尺寸碳纤维模型，拥有功能起落架与逼真座舱。设定为「10 马赫战机」：涡轮发动机低速起步，3.5 马赫后进气道隔板升起、超燃冲压点火，机体因激波加热通红，最终冲破 10 马赫并失去监控信号。其设计让人联想到传闻中的 SR-72，上映后进一步点燃了公众对该项目的想象。

10 马赫 超燃冲压
